# Reproduction boundaries

The selected implementation supports inspection and preparation for a fresh experiment. Exact scientific replay requires the separately retained original data, checkpoints, result arrays, protocol releases and environment bindings. Those payloads are deliberately excluded from these curated downloads. Preserving an implementation is not a claim that this ZIP alone reproduces the full archive.

Use a separate unsealed working tree for any future run. Preserve original source paths and hash-bound protocols as evidence; review root mapping and create fresh authorizations and ledgers before execution. Do not invoke completed stage commands in the original archive.

The historical scientific environment was Python 3.12.14, NumPy 2.5.4, SciPy 1.18.1, float64 CPU computation and one effective OpenBLAS thread per worker. Windows process/resource APIs support the ETEL adapter. Requirements are an inventory, not a cross-platform lock or an installation guarantee. No installed environment is bundled.

The retained delivery manifest declares 6,533,819,005 logical payload bytes, excluding its manifest and reserved sidecars. This is neither the curated ZIP size nor a RAM, disk or CPU minimum. The three release assets have separate sizes in their external seals.

The bounded package check uses only imports, CLI help and tiny in-memory calculations. It performs no training, official scoring, shot sampling or QPU work. Historical report results have not been recomputed for release.
