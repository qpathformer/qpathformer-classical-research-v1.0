# Reading the consolidated research edition

The [Research v1.0 collection](https://github.com/qpathformer/qpathformer-classical-research-v1.0/releases/tag/research-v1.0-20261031) was published on 31 October 2026 and is the Latest release. The main branch includes the same approved paper files and separate Research Approach. The controlled-content licence and trademark policy have been adopted. The owner approved public access on 31 October 2026. Start with [Q-Pathformer Routed States](papers/QPathformer_Main_Paper_v1.0.pdf), the main findings paper on classical models and quantum circuit simulation. It reports v0.6, v0.9 and v0.9.5 as distinct experiments, including negative and inconclusive findings.

Read [Q-Pathformer Three-State Architecture and Experimental Specification](papers/QPathformer_Architecture_and_Experimental_Specification_v1.0.pdf) for the proposed system, protocols, evidence map and unresolved questions. It is the architecture companion; the full integrated architecture remains unvalidated.

The [original architecture PDF](architecture/QPATH-ARCH-001.pdf) is preserved unchanged. Its first page records an introduction on LinkedIn on 5 December 2024. The [provenance record](architecture/README.md) distinguishes that introduction from the retained PDF's March 2026 creation and later repository additions.

The Papers ZIP includes those three works and ten supporting reports. The [repository release index](../README.md#release-index) links the individual Study, Documentation and Code assets. The [Research Approach](RESEARCH_APPROACH.md), [contribution rules](../CONTRIBUTING.md) and [publication notice](PUBLICATION_NOTICE.md) remain separate release documentation. The private v2.0 Lab programme is proposed future work; its membership rules are not part of either scientific paper.

The [collection cover](../assets/covers/QPathformer_Collection_Cover_v1.0.pdf) uses the overall Research Framework for Routed Learning title. Each new paper has its own title, cover, bibliography and metadata. Read [edition status](EDITION_STATUS.md) for current rights, release and public-access status.

The [main-paper change note](MAIN_PAPER_CHANGE_NOTE.md) and [architecture-companion change map](ARCHITECTURE_COMPANION_CHANGE_NOTE.md) document the preserved scientific content and the editorial status and metadata updates in `research-v1.0-20261031`. The superseded `research-v1.0` release entry was removed at the owner's request after the replacement was verified. Its original Git tag and verified private recovery archive are retained. The published replacement has its own package and manuscript identities; subsequent repository navigation updates do not change its sealed assets.
