# Q-Pathformer Study v0.1 — Local Benchmark and QPU Readiness — Documentation

Repository edition **v1.0** and study **v0.1** are separate identifiers. This is the final licensed study edition. “QPU readiness” means historical local circuit-translation and simulator checks, with no physical-QPU results or current-device qualification.

Start with the [study README](payload/project/README.md), [research guide](payload/project/RESEARCH_GUIDE.md), [study summary](payload/project/release_notes/study-v0.1.md) and [reproduction boundaries](payload/project/docs/REPRODUCIBILITY.md).

The documentation distinguishes the full benchmark, earlier prototype capsule and trained-circuit readiness checks. It describes one radial task and one text dataset; later four-task and ETEL studies are separate work. The [source index](payload/project/provenance/SOURCES.json) and [retained full-archive audit](payload/project/provenance/source_verification.json) identify the evidence.

Companion downloads are `QPathformer_v0.1_Study.zip` and `QPathformer_v0.1_Code.zip`. Raw datasets, trained checkpoints, installed environments and the full archive are retained separately. GitHub’s automatic source-code archives contain the tagged repository tree; use these named ZIPs for the curated packages.
